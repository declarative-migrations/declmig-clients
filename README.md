# declmig-clients

Polyglot SDKs under `clients/`. Rust, TypeScript, and Dart are first-class and modular. Other languages expose the same `/v1/health` surface.

AttoLang `*.atto` support is being added as a candidate, transport-agnostic
library boundary under [`clients/atto`](clients/atto/README.md). It is not
yet a complete or parity-admitted HTTP/JSON SDK.
